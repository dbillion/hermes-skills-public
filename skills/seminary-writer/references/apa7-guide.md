# APA 7 Citation Guide for Seminary Papers

## In-Text Citations

### Basic Format
- General reference: `(Author, Year)`
- With page number: `(Author, Year, p. 45)`
- Page range: `(Author, Year, pp. 45-47)`

### Examples
- `(Smith, 2020)`
- `(Smith, 2020, p. 45)`
- `(Smith, 2020, pp. 45-47)`

### Multiple Authors
- Two authors: `(Smith & Jones, 2020)`
- Three+ authors: `(Smith et al., 2020)`

### Direct Quotes
Always include page numbers:
> "The grace of God is sufficient for all things" (Smith, 2020, p. 45).

### Paraphrasing
Page numbers encouraged but not required:
> Smith (2020) argued that grace is sufficient for believers (p. 45).

## Reference List Format

### Book
```
Author, A. A. (Year). Title of book: Subtitle if any. Publisher.
```
Example:
```
Smith, J. D. (2020). Grace in the modern church: A theological study. Baker Academic.
```

### Edited Book
```
Editor, A. A. (Ed.). (Year). Title of book. Publisher.
```

### Chapter in Edited Book
```
Author, A. A. (Year). Title of chapter. In B. B. Editor (Ed.), Title of book (pp. xx-xx). Publisher.
```
Example:
```
Smith, J. D. (2020). Grace and salvation. In R. Johnson (Ed.), Theology for today (pp. 45-67). Baker Academic.
```

### Journal Article
```
Author, A. A. (Year). Title of article. Title of Journal, Volume(Issue), pages. DOI or URL
```
Example:
```
Smith, J. D. (2020). Grace in Pauline theology. Journal of Theology, 45(2), 123-145. https://doi.org/10.xxxx
```

### Journal Article (No DOI)
```
Author, A. A. (Year). Title of article. Title of Journal, Volume(Issue), pages.
```

### Bible
Not included in reference list. Cite in-text:
- `(John 3:16, NIV)`
- `(Eph. 2:8-9, ESV)`
- First time: `(English Standard Version, 2001/2016, Eph. 2:8-9)`
- Subsequent: `(Eph. 2:8-9, ESV)` or just `(Eph. 2:8-9)` if clear

### Lecture Notes
```
Instructor, A. A. (Year, Month Day). Title of lecture [Lecture notes]. Course Code, Institution. URL if available
```

### Website
```
Author, A. A. (Year, Month Day). Title of page. Site Name. URL
```

## Key Rules for Seminary Papers

1. **Alphabetize** by first author's last name
2. **Hanging indent** — first line flush left, subsequent lines indented 0.5"
3. **Double-space** entire reference list
4. **DOI format**: `https://doi.org/xxxxx` (preferred) or `doi:xxxxx`
5. **No retrieval dates** unless content changes (like Wikipedia — which you shouldn't use)
6. **Italicize** book titles, journal names, and volume numbers
7. **Capitalize** only first word of article titles (and proper nouns)
8. **Title case** for book titles, sentence case for article titles

## Common Mistakes to Avoid

- Don't include publisher location (APA 7 dropped this)
- Don't use "Retrieved from" before URLs unless there's a retrieval date
- Don't abbreviate journal names
- Don't include issue number if journal uses continuous pagination
- Don't put journal article titles in title case
- Don't forget to italicize the journal name AND volume number
- Don't include database names (like ATLA, JSTOR) for DOIs

## Quick Reference Card

| Source Type | In-Text | Reference List |
|-------------|---------|----------------|
| Book 1 author | (Smith, 2020) | Smith, J. (2020). Title. Publisher. |
| Book 2 authors | (Smith & Jones, 2020) | Smith, J., & Jones, M. (2020). Title. Publisher. |
| Book 3+ authors | (Smith et al., 2020) | Smith, J., Jones, M., & Brown, K. (2020). Title. Publisher. |
| Journal article | (Smith, 2020, p. 45) | Smith, J. (2020). Title. Journal, 1(1), 1-10. DOI |
| Chapter in book | (Smith, 2020) | Smith, J. (2020). Chapter. In M. Editor (Ed.), Book (pp. 1-10). Publisher. |
| Bible | (John 3:16, ESV) | Not in reference list |
| Lecture | (Smith, 2020) | Smith, J. (2020, Jan 15). Lecture title [Lecture notes]. |
