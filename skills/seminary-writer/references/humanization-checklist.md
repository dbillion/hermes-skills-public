# Humanization Checklist — Anti-AI-Detection

Run this checklist on every draft before submitting.

## Level 1: Word-Level Checks

### Banned Words Scan
Search for these words and replace:
- [ ] No "delve", "crucial", "pivotal", "leverage", "synergize"
- [ ] No "furthermore", "additionally", "moreover" — use "and", "so", "but"
- [ ] No "utilize" — use "use"
- [ ] No "facilitate" — use "help"
- [ ] No "demonstrate" — use "show"
- [ ] No "significant" — use "big" or "key"
- [ ] No "comprehensive" — use "full" or "complete"
- [ ] No "multifaceted" — use "complex" or "many-sided"
- [ ] No "realm", "landscape", "tapestry" (as metaphors)

### Simple Language Check
- [ ] Every word under 3 syllables where possible
- [ ] No jargon without explanation
- [ ] Contractions used naturally (don't, can't, it's, we're)
- [ ] Active voice preferred over passive
- [ ] No Latin or Greek unless necessary (and then translated)

## Level 2: Sentence-Level Checks

### Length Variation
- [ ] Mix of short (5-8 words) and long (15-25 words) sentences
- [ ] No two consecutive sentences same length
- [ ] At least one 1-2 word sentence per page for emphasis

### Structure Variation
- [ ] Not every sentence starts the same way
- [ ] Some sentences start with "And" or "But"
- [ ] Some sentence fragments used intentionally (sparingly)
- [ ] Questions used to engage reader (at least 2-3 per paper)

### Transition Check
- [ ] No formulaic transitions ("Furthermore", "In addition")
- [ ] Natural transitions: "So", "But", "Here's the thing", "Now"
- [ ] Some paragraphs start without transitions — just jump in

## Level 3: Paragraph-Level Checks

### Length Variation
- [ ] Short paragraphs (1-3 sentences) for emphasis
- [ ] Medium paragraphs (4-6 sentences) for development
- [ ] Long paragraphs (7-8 sentences) for complex arguments
- [ ] No two consecutive paragraphs same length

### Opening Check
- [ ] No paragraph starts with "In this section..."
- [ ] No paragraph starts with "It is important to note..."
- [ ] Each paragraph starts with substance, not filler

### Content Check
- [ ] Every paragraph has at least one of: personal reflection, story, question, specific example
- [ ] No paragraph is purely abstract argumentation
- [ ] At least 3 personal "I" statements in the paper

## Level 4: Paper-Level Checks

### Voice
- [ ] First person used where appropriate ("I believe", "I found", "This challenges me")
- [ ] Personal stories or ministry examples included (at least 2-3)
- [ ] Prayer moments or faith reflections included
- [ ] Contemporary application to modern church life
- [ ] Honest acknowledgment of complexity or uncertainty

### Structure
- [ ] Headings are descriptive and specific (not generic)
- [ ] Introduction has a hook (question, story, observation) — not "This paper will..."
- [ ] Conclusion is specific — not vague optimism
- [ ] No "Challenges and Future Prospects" formulaic section

### Authenticity Markers
- [ ] Specific dates or time references ("last Sunday", "in 2023")
- [ ] Real tools, platforms, or books mentioned by name
- [ ] Challenges or failures acknowledged
- [ ] Contrarian or unconventional viewpoint included (if honest)
- [ ] Humor or cultural reference (if natural)

## Level 5: Read-Aloud Test

Read the entire paper aloud. Check:

1. **Does it sound like a person talking?** If it sounds like a textbook, rewrite.
2. **Are there any tongue-twisters?** Simplify.
3. **Does it flow naturally?** Fix awkward transitions.
4. **Would you actually say this in conversation?** If not, why write it?
5. **Does it have personality?** Add opinions, reactions, feelings.

## The Coffee Test

Imagine explaining your paper to a friend over coffee. Would you:
- Use these exact words?
- Structure it this way?
- Include these examples?
- Sound this formal?

If the answer is no, rewrite until it passes the coffee test.

## Quick Score

Rate your draft 1-10 on each:

- [ ] Paragraph variety: ___/10
- [ ] Personal voice: ___/10
- [ ] Natural flow: ___/10

If any score is below 7, revise that area before submitting.
