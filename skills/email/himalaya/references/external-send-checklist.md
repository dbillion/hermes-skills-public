# External Send Checklist (Email)

Use this before any outbound email (especially when a credential file is mentioned).

## Confirmations to obtain

1) **Recipient** (email address)
2) **Subject line**
3) **Body content**
4) **From address** to send as
5) **Explicit permission to use any credential/API key file** referenced by the user
6) **Go-ahead to send now** (yes/no)

## Minimal confirmation template

"I can send this. Please confirm:
1) Recipient
2) Subject
3) Body
4) From address
5) Permission to use <credential file> for this send
6) Send now?"
