# Effective Java Skill Pack
## A Comprehensive Learning Resource Based on Joshua Bloch's "Effective Java" (3rd Edition)

> **Book:** *Effective Java* (3rd Edition) by Joshua Bloch  
> **Published:** 2018 (Updated for Java 9)  
> **Official Source Code:** [github.com/jbloch/effective-java-3e-source-code](https://github.com/jbloch/effective-java-3e-source-code)  
> **Author GitHub:** [github.com/jbloch](https://github.com/jbloch)

---

## What's Inside This Pack

This skill pack is designed to help you master the 90 items (best practices) from *Effective Java* through structured guides, annotated code examples, and quick-reference cheatsheets.

### Structure

| Folder | Contents |
|--------|----------|
| `chapters/` | Detailed markdown guides for all 11 chapters |
| `code-examples/` | Runnable Java code for key items |
| `cheatsheets/` | Quick-reference summaries |
| `resources/` | Links, references, and further reading |

---

## The 11 Chapters (90 Items)

| # | Chapter | Items | Focus |
|---|---------|-------|-------|
| 2 | Creating and Destroying Objects | 1–9 | Static factories, builders, singletons, dependency injection |
| 3 | Methods Common to All Objects | 10–14 | `equals`, `hashCode`, `toString`, `clone`, `Comparable` |
| 4 | Classes and Interfaces | 15–25 | Accessibility, immutability, composition, inheritance |
| 5 | Generics | 26–33 | Type safety, wildcards, PECS, varargs |
| 6 | Enums and Annotations | 34–41 | Enum patterns, annotations, marker interfaces |
| 7 | Lambdas and Streams | 42–48 | Functional programming, stream best practices |
| 8 | Methods | 49–56 | Parameter validation, defensive copies, method design |
| 9 | General Programming | 57–68 | Local variables, libraries, `float`/`double`, strings, reflection |
| 10 | Exceptions | 69–77 | Checked vs unchecked, failure atomicity, documentation |
| 11 | Concurrency | 78–84 | Synchronization, executors, lazy initialization |
| 12 | Serialization | 85–90 | Alternatives to serialization, serialization proxies |

---

## How to Use This Pack

1. **Start with `SKILL.md`** for the full learning path and study plan.
2. **Read each chapter guide** in `chapters/` — they summarize every item with key takeaways.
3. **Run the code examples** in `code-examples/` to see patterns in action.
4. **Use `cheatsheets/`** for quick revision before interviews or code reviews.
5. **Refer to `resources/`** for official links and community repos.
