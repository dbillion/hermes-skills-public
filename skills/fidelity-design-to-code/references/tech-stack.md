# Tech Stack for High-Fidelity Projects (2026)

## UI & Styling
- **shadcn/ui**: Collection of reusable components built with Radix UI and Tailwind CSS.
- **Tailwind CSS**: Utility-first CSS framework for rapid styling and design token implementation.
- **Radix UI**: Primitives for building accessible UI components.

## 3.D & Graphics
- **Three.js**: The industry standard for 3D on the web. Focus on `WebGPURenderer` for modern performance.
- **React Three Fiber (R3F)**: A React renderer for Three.js, making 3D scenes declarative.
- **Drei**: Helper library for R3F with useful abstractions (OrbitControls, Text, etc.).
- **GLSL / Fragment Shaders**: Custom shader code for high-performance procedural visuals.

## Motion & Animation
- **GSAP (GreenSock)**: Professional animation engine for complex timelines and scroll-driven effects.
- **Theatre.js**: A motion design toolset for the web. Provides a visual editor to direct scenes.
- **Anime.js (v4)**: Lightweight physics-based animation library for modular UI interactions.
- **Barba.js**: Pre-fetching and transition logic for multi-page applications.

## AI & Design-to-Code
- **Google Stitch**: AI design tool for "vibe-based" UI generation.
- **Fusion (Builder.io)**: Tool for converting Figma designs into codebase-aware React code.
- **Antigravity / Gemini CLI**: AI agents that can read `DESIGN.md` and implement code following design systems.
