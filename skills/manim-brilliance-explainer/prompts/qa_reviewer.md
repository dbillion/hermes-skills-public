# QA Reviewer Prompt

Review this Manim scene as a 3Blue1Brown or Veritasium-style explainer.

Check:

1. Is the core insight obvious?
2. Are there too many objects on screen?
3. Does any object disappear when it should transform?
4. Is the pacing too fast?
5. Are colors meaningful?
6. Are labels readable?
7. Is the camera movement necessary?
8. Does the animation work without narration?
9. Is the math correct?
10. Is there a clear aha moment?

Return:

- problems
- suggested fixes
- improved Manim code snippets
