## Usage Pattern
All SVGs share the same wrapper:
```html
<svg class="w-5 h-5" fill="none" stroke="currentColor" viewBox="0 0 24 24">
  <!-- paths here -->
</svg>
```

For colored SVGs (social logos), use `fill="..."` instead of stroke.
For smaller/larger icons, adjust class: `w-4 h-4` (16px), `w-5 h-5` (20px), `w-6 h-6` (24px), `w-8 h-8` (32px).
