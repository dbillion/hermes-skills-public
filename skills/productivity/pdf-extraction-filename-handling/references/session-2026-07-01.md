Session 2026-07-01: PDF text extraction for resume and certificates.

We attempted to extract text from several PDFs stored in ~/.hermes/cache/documents/ using the helper scripts from the ocr-and-documents skill. The script extract_pymupdf.py failed with a FileNotFoundError because the filename contained spaces and the argument was not properly quoted when calling the script via the terminal tool.

We then used pdftotext directly with proper quoting, which succeeded.

Key takeaways:
- When filenames contain spaces, always quote the path in shell commands.
- The helper scripts expect a single argument but still require proper quoting when invoked from a shell.
- For quick extraction, pdftotext is reliable and fast for text-based PDFs.
- For scanned PDFs or those needing OCR, marker-pdf would be appropriate (requires more disk space).
