# Quasar CLI Reference

## Project Management
- `npm init quasar`: Create a new project.
- `quasar dev`: Start development server.
- `quasar build`: Build for production.
- `quasar build -m [mode]`: Build for specific mode (spa, pwa, cordova, capacitor, electron, ssr).

## Development
- `quasar new [type] [name]`: Create new component, page, layout, store, boot file.
- `quasar inspect`: Inspect the generated Vite/Webpack config.
- `quasar info`: Display project info and environment.

## App Extensions
- `quasar ext list`: List installed extensions.
- `quasar ext add [ext-id]`: Add an extension.
- `quasar ext remove [ext-id]`: Remove an extension.
- `quasar ext invoke [ext-id]`: Run an extension's install script again.
