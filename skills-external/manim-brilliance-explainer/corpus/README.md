# Corpus Builder

Tools for extracting reusable animation patterns from public Manim repositories.

Recommended reference repos:

    git clone --depth=1 https://github.com/3b1b/manim.git grant-manim
    git clone --depth=1 https://github.com/ManimCommunity/manim.git community-manim

Then run:

    python corpus/build_corpus.py

This produces:

    corpus/manim_corpus.json
