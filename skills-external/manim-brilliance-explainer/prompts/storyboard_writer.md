# Storyboard Writer Prompt

Convert a topic into a beat-by-beat animation storyboard.

Use this structure for each beat:

- id
- narration
- visual action
- animation type
- duration in seconds

Rules:

1. Start with a hook.
2. Introduce only one core object at a time.
3. Create tension or curiosity before the main transformation.
4. Use transformation, not replacement.
5. End with a concise visual recap.
6. Keep total on-screen objects low.
7. Each beat should advance understanding.
