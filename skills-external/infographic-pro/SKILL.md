# Infographic Pro

This skill transforms complex historical and marketing data into high-converting 4:3 infographics.

## Core Workflow

1.  **Data Distillation**: Identify the 10-19 key data points (Kings/Books).
2.  **Style Rotation**: Generate 3 distinct variations:
    -   *Modern*: Professional, clean, and trusted.
    -   *Epic*: Historic, weighted, and traditional.
    -   *Shonen*: Energetic, youthful, and bold.
3.  **Prompt Engineering**: Use the `nanobanana_generate_image` or `generate_diagram` tools with the "4:3 aspect ratio" and specific style keywords.

## Technical Specs
- **Format**: 1600x1200 (Landscape).
- **Guidelines**: See [references/infographic_specs.md](references/infographic_specs.md).

## Usage Pattern
"Generate a 4:3 modern professional infographic for [Data] focusing on [Theme]. Include a 'Buy Now' call to action."
