# Superpowers Skills Collection

A curated collection of proven development skills adapted for pi. These skills establish disciplined workflows for planning, implementing, debugging, and reviewing code.

## Available Skills

This is a meta-skill that references all superpowers skills. Invoke individual skills via:

- `/skill:brainstorming` — Before any creative work
- `/skill:test-driven-development` — Before writing any implementation code
- `/skill:systematic-debugging` — When encountering bugs or unexpected behavior
- `/skill:writing-plans` — When you have a spec for a multi-step task
- `/skill:executing-plans` — When you have a written plan to execute
- `/skill:subagent-driven-development` — When executing plans with independent tasks
- `/skill:dispatching-parallel-agents` — When facing 2+ independent tasks
- `/skill:finishing-a-development-branch` — When implementation is complete
- `/skill:verification-before-completion` — Before claiming work is done
- `/skill:writing-skills` — When creating new skills
- `/skill:using-git-worktrees` — When starting feature work needing isolation
- `/skill:receiving-code-review` — When receiving code review feedback
- `/skill:requesting-code-review` — When completing tasks or before merging

## How to Use

When any task matches a skill's triggering conditions, follow that skill before proceeding. If you think there's even a 1% chance a skill might apply, invoke it.

NEVER skip a relevant skill. This is not optional.
